# MatchAPI Documentation

MatchAPI is a JSON Schema-based format for describing financial messaging APIs in a structured, machine-readable way.

This Wiki reflects the latest documentation synced from the main branch of the MatchAPI schema repository. For documentation matching an older schema release, browse the corresponding repository tag and read `docs/wiki/`.

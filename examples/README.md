# Examples

This directory contains example MatchAPI dictionaries.

## Minimal example

`minimal-api.matchapi.json` is a small valid MatchAPI dictionary intended to show the basic structure of the format.

It is not intended to describe a production trading API.

## Real-world examples

Real-world examples should only be published if the relevant API owner has approved publication.

Do not commit confidential client or venue dictionaries to this repository.
